Important boundaries:

- Service workers require HTTPS or localhost and do not operate under file://.
- Live NWS/OpenFEMA data requires network access and is retrieved only on user action.
- Shared multiplayer data is not end-to-end encrypted by the reference server; deploy behind TLS and apply appropriate access controls for real-world use.
- SHA-256 checks integrity of file bytes, not authorship or provenance by itself.
